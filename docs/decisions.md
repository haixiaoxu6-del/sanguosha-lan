## 0. 项目目标

- 局域网联机网页版三国杀。
- 首版两个模式：**3 人斗地主**、**1v1 人机对战**。
- 后续可加身份局、国战、单挑等模式。
- 所有文件写在 `D:\三国杀\`。

## 1. 模式

### 1.1 斗地主

- 3 人：1 地主 + 2 农民。
- 地主公开；两个农民互相知道。
- 地主随机产生（首版不做抢地主）。
- 地主：体力上限 +1、先手、额外技能【英姿】（摸牌 +1）。
- 农民：一个农民阵亡后，另一个农民摸 2 张。
- 胜负：地主死 → 农民胜；两个农民都死 → 地主胜。
- **不要“跋扈”**。

### 1.2 人机对战（1v1）

- 2 人：玩家 vs AI。
- 玩家先从 3 个武将中选 1 个；AI 从剩下 2 个中随机选 1 个。
- 双方满血；玩家先手；无地主加成。
- 胜负：谁先 0 血谁输。
- AI 首版用简单优先级，不偷看玩家手牌。

### 1.3 大厅

- 点亮：**斗地主**、**人机对战**。
- 灰色占位：**身份局**（不实现）。
- 以后加模式只加 `modes/*.js`，不改大厅结构。

## 2. 武将

- 首版 3 个（标包）：**关羽（武圣）、张飞（咆哮）、赵云（龙胆）**。
- 武将池、技能表都放 `data/`，可增删。
- 地主额外获得【英姿】；如果武将本身有英姿，去重。

## 3. 牌堆

- 60 张核心牌，无装备、无闪电、无桃园、无五谷、无借刀。
- 杀 14、闪 10、桃 6、决斗 4、过河拆桥 4、顺手牵羊 4、无中生有 4、南蛮 3、万箭 3、**兵粮寸断 4**、**无懈可击 4**。
- 锦囊使用后进入【无懈可击】窗口；简化版：无懈不可被反无懈。
- **兵粮寸断替代乐不思蜀**。
- 兵粮寸断：延时锦囊，距离 1；判定非梅花 → 跳过摸牌阶段。
- 3 人局所有人距离 1；7 人局再补距离/装备。

## 4. 交互

- **拖牌**：按住手牌 → 拖到合法目标 → 松开鼠标 = 直接出牌。
- 拖空 / Esc = 取消，牌回手牌。
- **点击流**：点牌 → 点目标 = 出牌；点目标前有“取消”。
- 无目标牌（桃/无中生有/南蛮/万箭）：点牌后“使用/取消”，或拖到中间出牌区。
- 多目标牌：点选多个目标 → “确定”；可取消。
- 主动技（非锁定）：点技能 → 选目标/选牌 → “确定”；可取消，取消不付代价。
- 锁定技：自动触发，无取消。
- **取消 ≠ 放弃**：取消=撤销选择；放弃=不响应。
- 选目标时：合法目标高亮，非法目标变暗并提示。
